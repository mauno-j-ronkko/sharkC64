# Importing an existing module as library module to the project

You can import an existing module to the project as library module from the File menu.

![File menu](../../images/menu/file.png)

To import a module, select the "Import Library..." item.
It opens a dialog, where you can select the module to be imported as library module.

![Import module dialog](../../images/dialog/import-module.png)

Once, you have selected the module, it is added to the project as library module and shown in the editor view.

![Imported library module in the project](../../images/project/imported-library.png)

Note that the import action fails, if you already have a module with the same name in the project.
Also, if you have project open, and you download a library from the Help menu,
it will automatically be added to the project.
